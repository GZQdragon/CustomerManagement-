# CustomerManagement-
一个简单的基于python与mysql数据库的客户管理系统
注：本地无需下载MYSQL的请使用第一个SQLite
  本地部署的有MYSQL的可以运行第二个原生代码（输入数据后可在本地的数据库里查看编写）
==========================================
         客户管理系统 — 使用说明
==========================================
【一、这是什么？】
    一个简单的客户信息管理小工具。
    可以添加、查看、修改、删除客户，按来源统计人数，
    还能把客户列表导出成 Excel 能直接打开的文件。
    客户数据保存在程序旁边的 customers.db 文件里。
【二、需要准备什么？】
    只需要一台 Windows 电脑（Win10 / Win11 均可）。
    不需要安装任何数据库软件，双击即用。
【三、怎么启动？】
    双击"客户管理系统.exe"。
    会弹出一个黑色命令行窗口，按菜单提示操作即可。
    关闭窗口 = 退出程序。
【四、功能菜单说明】
    1. 添加客户
       依次输入：姓名、手机号、邮箱、客户来源。
       手机号或邮箱格式不对时，程序会提示重新输入。
    2. 查看所有客户
       以表格形式显示全部客户（ID、姓名、手机号、邮箱、来源）。
    3. 修改客户
       先输入要修改的客户 ID，再选择要改的字段
       （1 姓名 / 2 手机号 / 3 邮箱 / 4 来源）。
    4. 删除客户
       输入客户 ID，程序会二次确认，输入 y 才真正删除。
       （ID 可以在"查看所有客户"里看到）
    5. 按来源统计客户数量
       统计"朋友推荐 / 广告 / 网络 / 其他"各有多少人，并显示合计。
    6. 导出客户列表到 customers.csv
       在程序所在文件夹生成 customers.csv，
       用 Excel 打开不会乱码，方便打印或存档。
    7. 退出
【五、常见问题】
    Q1：打开后提示"数据库打开失败"？
        A：说明程序所在文件夹不可写。请把 exe 放到
           普通文件夹（如桌面或 D 盘）再运行，不要放在
           系统盘受保护的位置。
    Q2：数据会不会丢？
        A：数据都保存在 customers.db 文件里。只要这个文件
           不丢、程序不卸载，数据就一直都在。
           建议定期备份（见第六节）。
    Q3：运行很慢/杀毒软件报警？
        A：首次启动需要解压运行，慢几秒正常；杀毒软件误报是
           打包程序的常见现象，点"允许/仍要运行"即可。
【六、数据备份（重要！）】
    备份 = 复制文件：
      关闭程序后，把 customers.db 文件复制一份到 U 盘或
      网盘保存即可（比如每周复制一次）。
    换电脑/重装系统：
      把 customers.db 和新电脑上的 exe 放在同一个文件夹，
      数据就全部回来了。
