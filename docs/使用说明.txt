==========================================
      客户管理系统 — 使用说明（图形界面版）
==========================================

【一、这是什么？】

    一个客户信息管理小工具，界面像登录/注册页面：
    姓名、手机号、邮箱、来源、备注一次填完，点一次「保存」就行，
    ★ 不用再像老版本那样一项一项按回车了。

    功能：新增客户、修改客户、删除客户、搜索筛选、
          按来源统计人数、导出 Excel 能直接打开的表格文件。

    客户数据保存在程序旁边的 customers.db 文件里，
    和老版本（黑窗口版）的数据完全通用，旧数据会自动兼容。


【二、需要准备什么？】

    只需要一台 Windows 电脑（Win10 / Win11 均可）。
    不需要安装 Python，也不需要安装任何数据库软件，双击即用。


【三、怎么启动？】

    方式一（推荐）：双击「客户管理系统.exe」。
    方式二：装有 Python 的电脑上，双击「客户管理系统（图形界面）.py」。

    两种方式用的是同一个 customers.db，数据互通。


【四、界面怎么用】

    界面从下到上分成三块：上面填信息，中间搜索，下面看列表。
    右上角一直显示「共 N 位客户」，筛选时会变成「筛选出 M / 共 N 位」。

    1. 新增客户（最常用）
       上半部分的表单，一次把信息填完：
         姓名 *      必填
         手机号 *    必填，11 位数字，如 13812345678
         邮箱        没有邮箱可以留空（程序会自动记成「无」）
         来源        下拉选择「朋友推荐 / 广告 / 网络 / 其他」，
                     也可以自己手动输入别的来源
         备注        选填，比如「已加微信」「下周回访」
       填好后点「保存」，或者直接按键盘回车键。
       保存成功后表单会自动清空，可以接着录下一位客户。

       如果哪一项填得不对，程序会：
         · 把那个输入框标成红色
         · 在表单右上角（"新增客户"那一行的右边）用红字说明哪里不对
         · 光标自动跳回那一项，改完再点保存即可

       保存成功后，新录入的那一行会在列表里短暂高亮一下，
       方便你一眼看到"刚存的这位客户排在哪"。
       （如果当时正开着搜索/筛选，程序会自动清掉筛选条件，
         免得新客户被条件挡住、看起来像没存上。）

    2. 修改客户
       在下面的列表里点选某一行，再点「修改选中」（或者直接双击那一行），
       信息会填进上面的表单，改好后点「保存修改」。
       点「取消修改」则放弃本次修改。
       表单标题会显示成「修改客户（ID=x）」，一眼能看出在改哪一条。

    3. 删除客户
       在列表里点选某一行 → 点「删除选中」→ 弹出确认框，点「是」才真正删除。
       （也可以选中后按键盘 Delete 键）
       注意：删除后无法恢复，重要数据请先导出备份。

    4. 搜索 / 筛选
       在「搜索」框里输入几个字，列表会实时过滤，
       姓名、手机号、邮箱、来源、备注都能搜。
       右边的「来源」下拉框可以只看某一类客户。
       只有真的在筛选时，右边才会出现「清空筛选」按钮，点它恢复全部。
       如果一个都没搜到，列表中间会提示怎么办。
       快捷键：Ctrl+F 跳到搜索框，F5 刷新列表。

    5. 按来源统计
       点「按来源统计」，会从按钮上方弹出一个小面板，
       显示每个来源有多少人、占比多少（带横条对比）。
       弹出时整个背景会变暗，把注意力集中在这块面板上；
       看完点「关闭」或按 Esc 即可。

    6. 导出 Excel（CSV）
       点「导出 Excel(CSV)」，选择保存位置（默认文件名 customers.csv），
       导出的是全部客户（不受搜索结果影响）。
       导出完成后会问你要不要直接打开，用 Excel 打开中文不会乱码。

    7. 其它小技巧
       · 点表头（ID / 姓名 / 手机号 …）可以按这一列排序，
         再点一次反向排序，表头上会出现 ▲ / ▼ 指示当前方向
       · 鼠标划过列表某一行时，那一行会浅浅变色，方便横着读一整行
       · 按回车 = 保存，按 Esc = 清空表单重填
       · 列表里双击一行 = 载入表单修改


【五、数据保存在哪？怎么备份？】

    所有数据都在 customers.db 这一个文件里，
    它和 exe（或 .py 文件）放在同一个文件夹。

    备份 = 复制文件：
       关闭程序后，把 customers.db 复制到 U 盘或网盘保存即可
       （比如每周复制一次）。

    换电脑 / 重装系统：
       把 customers.db 和新电脑上的 exe 放在同一个文件夹，数据就全回来了。


【六、常见问题】

    Q1：双击 exe 没反应，或者提示「数据库打开失败」？
        A：多半是程序所在的文件夹不可写。请把 exe 放到普通文件夹
           （如桌面、D 盘）再运行，不要放在系统盘的受保护位置。

    Q2：运行很慢 / 杀毒软件报警？
        A：首次启动需要解压运行，慢几秒正常；打包程序被误报是常见现象，
           点「允许运行 / 仍要运行」即可。

    Q3：界面字太大或太小？
        A：程序会自动跟随 Windows 的缩放设置。想调整可以右键桌面 →
           显示设置 → 缩放比例，重新打开程序即可。

    Q4：手机号必须是 11 位吗？
        A：是。规则是「1 开头、第二位 3-9、共 11 位」。
           如果以后要录座机或其他国家号码，告诉维护人员改一下校验规则。

    Q5：老版本（黑窗口那个）还能用吗？
        A：能用。旧的控制台版程序和 exe 都还留着，它们和图形界面版
           共用同一个 customers.db，数据完全一致。


【七、文件清单】

    客户管理系统.exe                    ← 双击这个（图形界面版）
    客户管理系统（图形界面）.py          ← 图形界面版的源码
    客户管理系统（旧版-控制台）.exe      ← 旧的黑窗口版（保留备用）
    Customer Management (SQLite).py     ← 旧的控制台版源码（保留备用）
    Customer Management.py              ← 更早的 MySQL 版源码（保留备用）
    customers.db                        ← 你的客户数据（重要！注意备份）
    customers.csv                       ← 导出的表格文件
    test_customer_gui.py                ← 自动化自检脚本（见下方说明）
    _shot\                              ← 界面预览图
                                          （界面预览.png、按来源统计弹层.png）

    小提示：图形界面版第一次打开需要解压，慢 3～8 秒是正常的，
            之后就快了。若程序异常退出，同目录会出现「错误日志.txt」，
            把它发给维护人员即可定位问题。

    关于自检脚本：以后如果改了程序代码，可以在本文件夹里执行
        python test_customer_gui.py
    它会自动跑 59 项检查（增删改查、格式校验、搜索、统计、导出等），
    用的是你客户数据的"副本"，不会改动真正的 customers.db。
